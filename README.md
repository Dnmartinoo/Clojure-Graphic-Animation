## Descripción del Proyecto

La aplicación genera una animación de **256 cuadros** donde cada cuadro es una imagen de **256×256 píxeles** (RGB 0–255). El color de cada píxel se calcula evaluando un **lenguaje sencillo** (código ingresado por el usuario) sobre una **máquina virtual (VM) pura** que se reinicia por píxel con estado.
